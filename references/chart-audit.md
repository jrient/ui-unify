# 图表色板实测（v1.8.0）

图表色板与 `data-palette`（12 套色系）、`data-accent`（6 种强调色）**正交**：全局只有这一套，亮/暗双值。
换色系、换强调色都不动图表色——同一份数据在任何主题下颜色含义不变，这是刻意的取舍。

来源：Anthropic `dataviz` skill 的参考色板实例（8 槽固定顺序，已做 CVD 排序寻优）。
本体系**只改了一个值**：浅色侧第 4 槽黄由 `#eda100` 加深为 `#c98500`——本体系浅色是暖纸画布
（最亮卡片面 `#fffdf5` / `#f9f3d8`），原值在其上实测只有 1.94:1，基本看不见。改完全部门槛重跑通过。

## dataviz 校验器实测（相邻对，即堆叠/柱/折线的默认用法）

校验器：`dataviz` skill 的 `scripts/validate_palette.js`（OKLab ΔE×100 + Machado CVD 模拟 + OKLCH 明度带 + WCAG 对比度）。
挑本体系**最极端的卡片面**做上下界：

| 模式 | 卡片面 | 明度带 | 彩度 | 相邻 CVD ΔE | 常色觉 ΔE | 对比度 |
|---|---|---|---|---|---|---|
| light | `#faf9f6`（默认） | PASS | PASS | 9.2 (deutan) | 18.0 | 3 色 <3:1，需兜底 |
| light | `#fffdf5`（solarized，最亮） | PASS | PASS | 9.2 | 18.0 | 2 色 <3:1 |
| light | `#f9f3d8`（gruvbox，最暖） | PASS | PASS | 9.2 | 18.0 | 4 色 <3:1 |
| dark | `#232324`（默认） | PASS | PASS | 8.4 (protan) | 19.3 | 全部 ≥3:1 |
| dark | `#1f1d2e`（rose-pine，最暗） | PASS | PASS | 8.4 | 19.3 | 全部 ≥3:1 |
| dark | `#2e3440`（nord，最亮的暗卡片） | PASS | PASS | 8.4 | 19.3 | green 2.53 |

门槛：相邻 CVD ΔE ≥ 8（6–8 是只有配了第二编码才合法的下限带）；常色觉 ΔE ≥ 15 是硬门槛。

**「<3:1 需兜底」是义务不是提示**：这些色在浅底上偏弱，所以每张图都必须配
直接标注 / 图例 / 可展开的数据表格（`.ui-chart-a11y`）——demo 里每张图都配齐了。

## 散点 / 气泡 / 地图：只用前 3 槽

这类图所有系列两两同屏，要按 all-pairs 校验。实测：

- light `#faf9f6`：前 3 槽 CVD ΔE 9.2 / 常色觉 24.0 → PASS
- dark `#232324`：前 3 槽 CVD ΔE 9.4 / 常色觉 20.9 → PASS

第 4 槽一进来，黄与橙同屏就掉出门槛。**散点类超过 3 个系列 → 分面或并入「其他」。**

## 顺序 / 序数 / 发散

- **顺序渐变**（连续量级，热力图）`--chart-seq-1…7`：单色相蓝。浅色由浅到深、深色由深到浅，
  统一口径是「离画布越远 = 值越大」。审计脚本校验它在 12 套色系 × 明暗下对比度**单调递增**。
- **序数渐变**（离散有序，漏斗/档位）`--chart-ord-1…4`：比连续渐变收窄，因为最靠近画布的一端
  仍要 ≥2:1。实测 12 套色系 × 明暗全部 ≥2.25。
- **发散** `--chart-div-neg-2 … --chart-div-pos-2`：蓝 ↔ 红，中点是中性灰（中点绝不用色相，
  否则「零」看起来像一类数据）。两臂按 OKLCH 明度对称取值，各自单色相、明度单调，实测：
  浅色红臂 3.75→、蓝臂 3.46→；深色红臂 3.97→、蓝臂 4.32→，`--ordinal` 四项全 PASS。

## 状态色不占分类槽

图表里的「成功/重试/失败/排队」直接复用体系已有的 `--ok`/`--warn`/`--danger`/`--idle`
（这四个已在 `contrast-audit.md` 过 AA）。它们与分类槽刻意错开，但**同色相家族仍可能靠近**——
所以状态永远配图标或文字，绝不只靠颜色。
